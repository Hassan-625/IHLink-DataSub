# IHLink mobile artwork

Created with the built-in image-generation tool. Optimised WebP assets are in `public/mobile/`. Feature panels are rendered from app UI code so labels, network branding and service routes stay editable. These are illustrative previews, not customer data.

DataSub uses deep teal and charcoal with warm gold accents. SchoolPro uses charcoal and warm gold. All welcome slides include feature-specific UI previews and descriptions. Website layouts remain separate.

## Artwork prompts
- data-everyday: Nigerian woman using her phone; refined to include IHLink branding and a visible DataSub screen with Data, Airtime, Bills and MTN, Airtel, Glo and T2.
- data-bills: Nigerian man using a phone, warm natural lighting, clean composition for a bills-and-services banner.
- data-connect: Two Nigerian friends connecting through their phones, friendly natural scene, space for onboarding copy.
- school-community: Nigerian school proprietor and teacher, professional school setting, school community theme.
- school-results: Nigerian teacher using a tablet, organised classroom, assessment and results theme.
- school-family: Nigerian parent and child, positive school-family connection theme.

The artwork is combined with coded previews of actual wallet, services, dashboard, result and family-access layouts. No invented prices, balances or payment successes are presented.
